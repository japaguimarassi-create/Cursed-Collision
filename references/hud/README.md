# Collision Battlestar HUD AI References

Put the approved visual reference images for the HUD generator in this directory.

Recommended set:
1. battleground combat HUD
2. mobile combat controls
3. shop/progression UI
4. city/lobby HUD

The generator accepts PNG, JPG and WEBP and uses at most four primary references per generation pass.

Do not place API keys in this directory or anywhere in the repository.
