# STEAL AN ANIMAL — Project Guide

## Overview

**Steal An Animal** is a mobile-first Roblox simulator about capturing wild animals, escaping a giant animal guardian, returning to your farm, placing the animal in a barn, and collecting its passive coin income. The experience has no Strength stat, no bench-press system, and no instant sale on contact.

The map is generated by the server from native Roblox parts so it is reproducible in Rojo builds. The current version has eight personal farms, six sequential biomes, 23 species, six giant animal guardians, server-side capture validation, persistent barn inventories and bounded offline income.

## Research and design direction

The map layout was informed by the live [Steal An Egg Roblox experience](https://www.roblox.com/games/107778070777162/Steal-An-Egg), its [biome guide](https://www.ign.com/wikis/steal-an-egg-roblox/All_Biomes), the game's [biome and guardian overview](https://games.gg/roblox/guides/steal-an-egg-biomes-guide/), Roblox's [environment art curriculum](https://create.roblox.com/docs/tutorials/curriculums/environmental-art/construct-your-world), [instance streaming documentation](https://create.roblox.com/docs/workspace/streaming), [performance guidance](https://create.roblox.com/docs/performance-optimization/design), [adaptive UI guidance](https://create.roblox.com/docs/production/publishing/adaptive-design), and [UI/UX design guide](https://create.roblox.com/docs/production/game-design/ui-ux-design).

The design applies a bright, readable simulator layout without copying other games' meshes, logos, scripts or exact maps. Each biome gets a clear color family, landmark silhouettes and one oversized animal guardian. The supplied Zxgly model pack inspired the visual system; this Rojo build recreates its panel hierarchy and interactions rather than importing its binary model or executing its generic LocalScripts, which can assume unrelated remotes and currencies. The source pack is available at [Zxgly's free pack page](https://zxgly.itch.io/free-cartoony-roblox-ui-pack). The runtime UI is recreated with native Frames, UIGradients, strokes, scrollable cards and server-connected buttons so the pack's inventory, store, quests, daily rewards, settings and statistics concepts match this game's actual economy.

## World layout

The map uses one broad return route with the hub and player farms near the beginning. A visible path joins six areas:

1. **Sunny Meadow** — grass, bright flowers, farm animals and a large bear guardian.
2. **Whispering Forest** — pine silhouettes, mushrooms, woodland creatures and a giant wolf guardian.
3. **Misty Wetlands** — shallow pools, reeds, rocks, amphibians and a massive crocodile guardian.
4. **Frost Peak** — snow floor, icy trees, blue crystals and a giant snow bear.
5. **Golden Savanna** — warm soil, acacia-shaped trees, boulders and a giant lion.
6. **Ember Volcano** — dark slate, glowing lava-colored crystals and a volcanic titan.

The biome entrance arches are visual landmarks; progression comes from the gameplay loop, guardian risk and the value of animals, not a Strength gate. The world uses native parts rather than unreviewed Toolbox scripts. The build runs each map section in a protected step, writes diagnostic attributes (MapReady, BaseCount, AnimalCount, BiomeCount) and emits the failing step into server output. The client displays a failure panel if the map does not become ready.

## Core gameplay loop

1. Spawn at your own farm.
2. Explore a biome and approach a wild animal.
3. Hold the **STEAL** prompt. You can carry one animal at a time.
4. The animal follows the player as a visual carry and heavier creatures slow the player.
5. A giant animal guardian can spot a player carrying prey, patrol, chase using pathfinding, and cause the carried animal to escape.
6. Reach your own green **STORE ANIMAL** pad and hold the prompt to save the animal into your barn.
7. Each stored animal adds its configured coin rate to the barn. Step on the gold **COLLECT COINS** pad to transfer the stored bank to your wallet.
8. The animals respawn in their original biome. The barn inventory and bank are saved with the player profile.
9. A bounded offline calculation awards income for up to six hours since the last saved income timestamp. Income is claimed atomically and the timestamp advances in the same DataStore update to avoid repeated offline claims.

## Economy and progression

### Animals

The server catalogue is the source of truth for each creature's biome, weight, rarity, initial value and IncomePerSecond. The client reads this catalogue for the animal index; it cannot decide which animal is captured, where it belongs or how many coins it generates.

### Movement

Base speed is:

    BaseSpeed = clamp((16 + SpeedLevel * 0.85) * SpeedMultiplier + VIPBonus, 16, 150)

The carry weight penalty is independent from Strength:

    Penalty = clamp(max(0, Weight - 8) * 0.008, 0, 0.55)
    CarrySpeed = max(7, BaseSpeed * (1 - Penalty))

The server applies movement speed. WalkSpeed is not itself an anti-cheat boundary, so a production competitive release should add server-side movement anomaly checks.

### Barn income

The base barn stores six animals. The Expanded Barn pass adds four slots. In-session income goes into a bank that the player collects manually. Offline income is capped at 21,600 seconds (six hours). The passes modify distinct systems: DoubleIncome multiplies passive barn income, DoubleSpeed modifies speed progression, VIPFarm adds movement and income bonuses, and ExtraBarnSlots expands barn capacity.

Rebirth requires the maximum speed level and a coin threshold. It resets Speed and wallet coins while keeping the barn collection and raises passive income by 10% per rebirth.

## UI

The GameClient.client.lua interface uses:
- A compact top HUD for coins, income per second, barn occupancy and speed.
- Five large mobile navigation buttons for Barn, Animals, Shop, Passes and More, with the Barn screen's Collect button securely wired to the server and only valid inside the player's own farm.
- Scrollable pages for the animal index, pass/product cards, quests, daily rewards, codes, stats, settings and rebirth.
- UIGradients, rounded cards, colored rarity markers, safe-area insets, viewport-based sizing and Activated handlers.
- A map-readiness overlay if the server reports missing map sections.

The UI pack's generic scripts are not loaded because they may assume unrelated folders, remotes, currencies and purchase IDs. The matching visual ideas are rebuilt as native elements tied to the actual server economy.

## Gamepasses and developer products

Configure actual IDs in src/RoubeUmAnimal/ReplicatedStorage/Shared/MonetizationIds.lua.

| Type | Key | Intended effect |
| --- | --- | --- |
| Pass | DoubleIncome | 2x barn income |
| Pass | DoubleSpeed | 2x speed gains |
| Pass | VIPFarm | movement and 25% income bonus |
| Pass | ExtraBarnSlots | 4 additional barn slots |
| Developer Product | SpeedBoost | repeatable +10 speed |
| Developer Product | CoinBundle | repeatable +5,000 coins |

IDs intentionally remain 0 until the items exist in the Roblox Creator Dashboard and their IDs are inserted. Purchase prompts are therefore not active yet. The receipt handler grants only recognized products and uses the persistent purchase ledger for idempotency.

## Build and publish

Project root: default.project.json

    rojo build default.project.json --output build/StealAnAnimal.rbxl

Validation runs:
- python3 tools/validate_roube_animal.py
- luau tools/tests/run.luau
- python3 tools/tests/test_map_layout.py
- python3 tools/tests/test_monetization.py
- Pinned Luau syntax parse over every Lua source
- Rojo place build and artifact upload

Publishing targets the existing confirmed Roblox Universe 5290480963 and Place 15338267657. The publisher requires the repository's ROBLOX_API_KEY secret and explicit release confirmation; it must not target a different experience.
