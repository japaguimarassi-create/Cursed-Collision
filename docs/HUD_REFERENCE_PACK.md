## Observed UI rules used by Cursed Collision

- Four primary skill slots stay grouped near the lower center.
- Combat actions remain visually separated from the four skills.
- The awakening/power meter sits directly above the skill group.
- Mobile gets large touch targets and keeps interaction controls away from device cutouts.
- Console gets controller glyphs while keeping the same action hierarchy.
- PC keeps the combat surface minimal and relies on hardware input instead of adding unnecessary on-screen buttons.

The exact live JJS control set changes with updates. Current public references confirm the baseline PC flow M1, 1–4, Q, F, R, G and the documented Xbox mapping B/Y/X/D-pad controls. See the sources in the project report before treating any screenshot as a canonical control map.
