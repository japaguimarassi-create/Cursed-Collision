# Collision Battlestar — HUD visual reference

The HUD uses original labels, layout and colors.

Design targets:
- compact top identity/status area;
- distinct route-map button;
- lower-left player resource meters;
- dedicated touch combat cluster;
- responsive modal panels;
- safe-area aware interactive controls;
- selectable route controls for gamepad use.

Technical references:
https://create.roblox.com/docs/production/game-design/ui-ux-design
https://create.roblox.com/docs/tutorials/use-case-tutorials/ui/create-hud-meters
https://create.roblox.com/docs/reference/engine/classes/GuiService

No external franchise UI asset is shipped or displayed by the runtime.
