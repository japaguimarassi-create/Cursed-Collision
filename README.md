# COLLISION BATTLESTAR

Where Worlds Collide.

Collision Battlestar is the active Roblox project in this repository. The Rojo manifest points exclusively to the Collision Battlestar runtime.

## Current vertical slice

- Battle Line continuous urban world
- M1, Heavy, Block, Parry, Dash, Special and Overdrive
- Blade and Martial styles
- Momentum and Instability
- server-authoritative combat, travel, rewards and persistence
- four enemy archetypes plus mini-boss and boss framework
- Battle Streak repeatable waves
- first-response quest and progression
- Collision State and Reality Break events
- mobile, keyboard and gamepad input
- procedural combat animation fallback
- bounded combat VFX with impact waves and blade-style traces
- verified free Creator Store hero props with procedural fallback
- verified free positional combat impact audio

## Asset policy

No copyrighted franchise characters, techniques or copied proprietary runtime assets are included.

AnimationDefinitions keeps an empty ID for each slot until a direct public Roblox AnimationId is independently verified. The procedural fallback therefore remains the authoritative animation path for unverified slots.

## Build pipeline

The project uses a Rojo source-of-truth manifest, GitHub Actions validation and a manual Roblox publication workflow. Static validation and Roblox acceptance do not replace live device testing for visual quality, combat feel, streaming behavior or sustained mobile frame rate.
